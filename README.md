# OmegaVault for desktop

Installers for the [OmegaVault](https://omegavault.app) desktop app. Download the newest version from **[Releases](https://github.com/iayvob/omegavault-releases/releases/latest)**:

| System | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `OmegaVault-<version>-mac-universal.dmg` |
| Windows (x64 and Arm) | `OmegaVault-<version>-win-*.exe` |
| Linux | `.AppImage` (any distribution) or `.deb` (Debian, Ubuntu) |

Once installed, the app checks for new versions on its own and offers **Restart to update**.

This repository only holds releases. The app is built from a private repository; there is no source code here.
